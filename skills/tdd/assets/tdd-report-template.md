# TDD report

- Objective and acceptance criteria:
- RED: test path, command, exit status, observed failure, why it demonstrates missing behavior.
- Implementation: change and existing authorization scope.
- GREEN: command, exit status, actual result.
- Quality: configured checks and outcomes; unavailable checks and reasons.
- Handoff: changed artifacts, remaining work, blockers, checkpoint location.

Examples and expected output do not establish a passing gate.
