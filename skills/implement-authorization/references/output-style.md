# Authorization verification report

Record the policy or ability changed, the action, and the actor roles exercised.

- Policy checks: exact test command, actual exit status, allowed and denied cases.
- Request checks: test command or request against a test environment, observed status and data isolation assertions.
- Manual check, when available: action attempted using test records, observed exception or response, and cleanup performed.

Label example commands as examples and expected responses as expectations. If a console or browser is unavailable, mark the manual check unrun and provide the executable automated coverage. Never simulate output as evidence. Reuse existing authentication and authorization libraries; add a library only when the task needs it and project conventions permit it.
